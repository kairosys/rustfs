# AGENTS.md — rustfs (runtime data + Kubernetes)

This workspace is **not the RustFS source repo**. It contains only generated runtime data and a Kubernetes deployment manifest. There are no Go/Rust sources, build scripts, linters, or test suites here.

## What’s in this repo

- `k8s/rustfs-deployment.yaml` — Service + Deployment + Ingress (3 documents, no namespace specified — deploys to current `kubectl` context namespace).
  - Container image: `rustfs/rustfs:latest`.
  - Container port **9000** (S3). Command: `["rustfs", "/data"]`.
  - Env: `RUSTFS_ADDRESS=0.0.0.0:9000`, `RUSTFS_SERVER_DOMAINS=s3.localhost,rustfs,rustfs.default.svc.cluster.local`.
  - Secrets via `secretRef: rustfs-secret` → `RUSTFS_ACCESS_KEY`/`RUSTFS_SECRET_KEY`.
  - Resources: 64Mi–256Mi memory, 50m–500m CPU.
  - Volume: hostPath `/mnt/workspaces/rustfs/data` → `/data` (`DirectoryOrCreate`).
  - Ingress hosts: `s3.localhost` + `*.s3.localhost`, class `nginx`, body-size `500m`.
- `k8s/rustfs-secret.yaml` — default credentials. Git-ignored via `.gitignore` (`*-secret.yaml`), but the file exists locally. Rotate before production; do not commit.
- `data/` — generated by the running container: RustFS layout under `.rustfs.sys/`, plus Langfuse event buckets under `langfuse-events/`. **Do not edit while RustFS is running.** Back up from `<host>/data`, not this repo dir — files here are consumed in place by the hostPath mount.

## Apply / change things

```bash
kubectl apply -f k8s/   # deploy or update (image, env, volume path)
```

- Changing `RUSTFS_ADDRESS` needs **both** the Deployment container env and the Service `port`/`targetPort`.
- Changing the Ingress host requires updating both `host:` rules (`s3.localhost` + `*.s3.localhost`) to match.
- Image uses `:latest`; pin a digest for reproducibility across nodes.

## Gotchas agents miss without this note

- No build/test/lint step exists in this repo — do **not** run `cargo`, `make`, or any package manager here; those commands have no targets and only waste time.
- The hostPath `/mnt/workspaces/rustfs/data` does not exist on a new node until first apply (Kubernetes `DirectoryOrCreate`): pre-create it if you need to seed data before deploying, otherwise the dir is auto-created empty.
- Ingress proxy body-size annotation is already set (`nginx.ingress.kubernetes.io/proxy-body-size: "500m"`); do not re-add it on service changes.
